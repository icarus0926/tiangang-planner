# 前端开发指南

## 代码地图

`public/index.html` 同时包含样式、页面骨架和全部脚本。定位功能时优先按函数名搜索：

| 区域 | 主要入口 |
| --- | --- |
| API、刷新、通用 mutation | `api`、`load`、`mutate`、`patchTask`、`createTask` |
| 树索引与共享控件 | `MAP`、`KIDS`、`cbHtml`、`bindCbs`、`treeAddRow`、`bindTreeRows` |

## 前端状态模型

- `DATA`：最近一次 `/api/data` 快照。
- `MAP`：`task.id -> task`。
- `KIDS`：`parent_id -> children[]`。
- `curPage`：当前导航页。
- `viewMonth`、`viewWeekMon`、`viewDay`：当前时间窗口。
- `monthMode`：月度甘特或大纲。
- `expanded`：普通任务树展开集合。
- `goalOpen`：年度目标卡展开集合。

`mutate()` 是标准写入入口：调用 API、显示结果、重新加载数据、执行 `renderAll()`。新增交互不要直接修改 `DATA` 后假装持久化；服务端成功响应后，以新快照为准。

## 五个页面

### 总览

展示 KPI 和 Canvas 任务全景图。图按目标形成簇，任务之间用父子边连接。支持：

- 过滤已完成节点以及按年/月/周/日尺度过滤。
- 聚焦目标簇或节点子树。
- 拖动节点；拖父节点时后代保持相对位置一起移动。
- 拖动后钉住、画布缩放和平移、hover 提示。
- 单击聚焦，右键回父级/上一层，双击跳到相关页面并定位任务。
- 标签需要碰撞规避；子节点名称也必须可见，不能只显示根名。

图算法是原生 Canvas 力导向模拟。修改力参数时同时检查：大簇是否充分散开、标签是否遮挡、拖父节点后子树是否变形、过滤切换是否残留旧 pin/焦点。

### 年度目标

目标卡展示手工进度、挂载任务数及叶子完成比。目标下新建根任务初始为 `goal`，留在目标区；用户点击 `→ 池` 后才变成未分配 pool 任务。任务行可展开子任务并进行增删改。

“本年已完成”按 `done_at` 月份分组，不按计划月份分组。

### 月度规划

含任务池、本月规划池、甘特/大纲和已完成区：

- 任务池按动态 `kind` 标签分组，不按优先级分组。
- 已分配根任务用深色卡片标识；卡片可跨标签区拖动改变分类。
- 标签可新增、改名和删除；删除后相关任务归入 `其他`。
- 本月规划池既显示仅有月份的任务，也显示已进入甘特的任务，并提供完整增删改、子任务、挂靠和退回操作。
- 完成任务在甘特中划线并排到未完成任务之后；进度由叶子完成比结算。

月度甘特和大纲共享任务数据与展开状态，但分别维护适合时间线和层级阅读的布局。

### 周计划

周页面是当前周一至周日的 7 天窗口。上方使用与月度页相同的甘特引擎；下方任务列表可按行展开并添加子任务。周任务可以拖入甘特排期，完成项进入周已完成分区。

不要增加持久化 `week` 字段。跨月的一周仍按实际日期计算。

### 每日执行

自由文本输入创建 execution；升格按钮显式创建任务。任务参考区只允许叶子加入当日待办，避免创建无法通过单次待办勾选完成的父任务关联。所有行可展开添加子任务。

## 甘特交互契约

1. 拖动按真实日期差计算，不按可见区域像素裁剪后的伪日期计算。
2. 拖父任务条时，所有已有日期的后代平移相同天数；无日期后代保持无日期。
3. 左右手柄只调整当前任务时长，不改变树结构。
4. 未排期子任务可在父范围显示幽灵条；点击后才写真实日期。
5. 无日期父任务的信封条来自有日期后代的最小/最大日期。取消信封排期会清空对应后代日期，这是批量操作。
6. × 固定在名称左侧独立槽位，长任务名必须截断，不能覆盖按钮。
7. 标签上下拖动只允许同一 `parent_id` 层排序；跨层排序必须拒绝。挂靠使用独立的 ⇄ 操作。
8. 完成根簇排序靠后并显示删除线，但仍保留查看和重开的入口。

## 分类与颜色

任务分类读取根节点的 `kind` 语义，子任务在树中通常跟随任务簇分类。动态标签来自 `DATA.tags` 与现有根任务分类的并集，`其他` 始终作为兜底。颜色由标签文本稳定哈希生成，不要在新增分类时维护硬编码颜色表。

标签改名/删除目前由前端先保存 tags，再逐任务 PATCH `kind`。这是多请求操作，修改时要考虑部分失败与刷新后的真实状态。

## 浏览器验证清单

涉及 UI 的提交至少检查：

- 视口较窄和长任务名时按钮仍可点击。
- 展开多层子任务后容器不溢出。
- 月/周跨边界任务拖动后的真实日期正确。
- 父任务完成、重开、移动时整棵子树结果正确。
- 分类拖拽、挂靠和同层排序不会互相串义。
- 全景图拖动、缩放、筛选、聚焦和跳转无控制台错误。
- 写入后刷新页面，状态仍与 SQLite 一致。
